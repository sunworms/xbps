🔧 Installation

1

Add this repository to your XBPS configuration:

echo "repository=https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME" \
  | sudo tee /etc/xbps.d/20-custom.conf
2

Sync the repository index. XBPS will prompt you to import the signing key — verify the fingerprint below before accepting.

sudo xbps-install -S
3

Install any package:

sudo xbps-install helix-git
sudo xbps-install helium-browser-bin
sudo xbps-install font-aporetic
